No launcher URL is configured

Kolto Desktop opens a launcher web app, but it was not told where to find it, or the value it was given is not an https URL (plain http is accepted on localhost only).

Set the URL in one of these ways; the first one set wins:

  1. Start the app with --launcher-url=https://launcher.example.
  2. Set the environment variable KOLTO_LAUNCHER_URL.
  3. Put {"launcherUrl": "https://launcher.example"} in app-config.json before packaging.
